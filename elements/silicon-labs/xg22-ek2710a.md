# Silicon Labs BRD2710A · xG22E Zephyr board target

- Board model reported by Zephyr: Silicon Labs BRD2710A (xG22 Explorer Kit)
- Zephyr board target: `xg22_ek2710a`
- MCU selected by the board device tree: EFR32MG22E224F512IM40
- Flash: 512 KB
- SRAM: 32 KB

This declaration records the board identity used by the G22E Zephyr baseline. The existing [EK8200A energy-harvesting kit declaration](xg22-ek8200a.md) is retained separately; a relationship between retail kit and board identifiers is not assumed here.
